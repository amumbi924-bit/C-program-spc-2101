# Modern Portfolio

A modern, responsive portfolio website built with HTML, CSS, and JavaScript.

## Features

- Responsive design that works on all devices
- Smooth scrolling navigation
- Animated skill cards
- Clean, modern layout

## Setup

1. Place your profile picture in the `portfolio` folder and name it `profile.jpg` (or update the `src` in `index.html`).
2. Open `index.html` in your web browser to view the portfolio.
3. Customize the content in `index.html`:
   - Replace `[Your Name]` with your actual name
   - Update the about text
   - Modify the skills section with your actual skills
   - Update contact information

## Customization

- **Styling**: Edit `styles.css` to change colors, fonts, and layout.
- **Interactivity**: Modify `script.js` for additional features.
- **Content**: Update `index.html` with your personal information.

## Browser Support

Works in all modern browsers. For older browsers, some animations may not display.

## Troubleshooting

- If images don't load, ensure the file path is correct.
- If styles don't apply, check that `styles.css` is in the same folder as `index.html`.
- For any issues, open the browser's developer console (F12) to check for errors.
